# vn-digital-trust

Prototype Bước 06 chạy local tại **https://localhost:8443**. Mốc 2026-10-27 đã có đăng nhập, quản lý tài khoản/quyền, đợt đánh giá, hệ thống/tài sản, bối cảnh, kịch bản và hồ sơ đọc cho consultant.

- [Trạng thái triển khai và kiểm chứng](docs/implementation/README.md)
- [Cách chuẩn bị hồ sơ và thêm kịch bản vào đợt](docs/implementation/workspace-v0.1.md)
- [Cách chạy lab](lab/local/README.md)
- [Cách tái lập kiểm thử workspace](docs/implementation/workspace-testing-v0.1.md)

Ứng dụng và dữ liệu Docker trên máy hiện tại lưu trong project ở ổ D. Tiếp tục dùng tài khoản đã tạo; không chạy lại bootstrap trên database đang dùng. Upload/xác minh bằng chứng, kết luận thẩm định và nghiệm thu CRM còn ở các mốc tiếp theo.
